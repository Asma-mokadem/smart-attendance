# Procedure de justification d'une absence

1. L'etudiant depose un justificatif (certificat medical, convocation officielle, etc.) au secretariat.
2. Le delai maximal est de 5 jours ouvrables apres l'absence.
3. Le responsable pedagogique valide ou refuse le justificatif.
4. Une absence justifiee n'est pas retiree du suivi, mais elle est marquee "justifiee" et ne compte pas dans les seuils.
5. Au-dela du delai, la justification est refusee, sauf cas de force majeure.
