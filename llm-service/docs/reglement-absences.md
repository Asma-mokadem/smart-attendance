# Reglement des absences

## Seuils
- Une absence est comptee lorsque l'etudiant ne badge pas pendant la seance.
- A partir de 3 absences non justifiees, l'etudiant recoit un premier avertissement par e-mail.
- A partir de 5 absences non justifiees, il est convoque par le responsable pedagogique.
- Un taux de presence inferieur a 70 % sur le semestre place l'etudiant en situation d'alerte.
- Un taux de presence inferieur a 50 % peut entrainer l'interdiction de passer l'examen de la matiere.

## Consequences
Les absences justifiees ne comptent pas dans les seuils ci-dessus.
